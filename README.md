# Prin Epic - Sistema de Gestión de Ventas

Sistema web para administrar pedidos, clientes, cupones, tickets y reportes de ventas para Prin Epic, negocio de camisetas y prendas personalizadas.

## Funciones principales

- Registro y edición de pedidos.
- Gestión de clientes.
- Historial de pedidos por fecha.
- Cálculo automático de precios por cantidad.
- Control de anticipos, saldos y pedidos saldados.
- Generación e impresión de tickets.
- Descarga y envío de tickets por WhatsApp.
- Sistema de cupones de descuento.
- Dashboard con resumen de ventas.
- Reportes y caja.
- Diseño responsive para computadora y móvil.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Supabase
- LocalStorage
- GitHub Pages
